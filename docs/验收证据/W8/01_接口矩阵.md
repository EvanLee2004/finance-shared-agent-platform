## C. 错误场景抽测（横切）

| 场景 | HTTP | code | 人话 message |
|------|------|------|----------------|
| 未登录 GET /me | 401 | auth_required | 未登录或会话已失效 |
| 登录失败 | 401 | auth_failed | 用户名或密码错误 |
| 校验失败 body 空 | 422 | validation_error | 请求参数无效：…（W8 修） |
| 非 admin sync | 403 | forbidden | 仅管理员可同步 Skills |
| 跨用户 chat | 404 | not_found | 会话不存在 |
| OC 离线发消息 | 503 | oc_unavailable | OpenCode 未就绪… |
