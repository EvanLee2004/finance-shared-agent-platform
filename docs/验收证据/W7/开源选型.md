# W7 开源选型表

| 领域 | 候选 | License | 结论 | 理由 |
|------|------|---------|------|------|
| Vue 组件 | **Element Plus** | MIT | **采用** | 仓内原无 UI 库；Button/Dialog/Empty/Skeleton/Message/Form 成熟，免自研组件库 |
| 图标 | **@element-plus/icons-vue** | MIT | **采用** | 与 EP 一致；导航/状态图标体系 |
| 主题 | 现有 CSS 变量 light/neon **扩展** | — | **保留扩展** | 禁止第三套互不兼容主题；用 CSS 变量桥接 EP 主色 |
| 动效 | CSS transition + EP 内置 | — | **采用** | 150–250ms；`prefers-reduced-motion` |
| 通知 | **ElMessage** | MIT | **采用** | 禁止 alert/confirm |
| 空态/骨架 | **ElEmpty / ElSkeleton** | MIT | **采用** | 统一四态，避免每页复制「暂无数据」 |
| VueUse | @vueuse/core | MIT | **不用本波** | 令牌/主题已有 theme.js；避免无必要依赖 |
| 自研设计系统 | — | — | **禁止** | MASTER 红线 |
| 利润看板组件 | — | — | **禁止** | 只可参考视觉节奏 |

## 未采用

- Naive UI / Ant Design Vue：与「默认 Element Plus」示例一致，换库无额外收益。
- 自写 Button/Table/Dialog：造轮子。
