## 与真实 bootstrap 对齐

| 来源 | 账号 | 密码 | 角色 | 如何进库 |
|------|------|------|------|----------|
| **`FSA_BOOTSTRAP_ADMIN_*`（推荐）** | **admin** | **Phase0Demo1!** | admin | 库中**无任何 admin** 时，启动 API lifespan 调用 `bootstrap_admin_if_needed` 创建 |
| LoginView 填入区 | demo | DemoUser1! | user | **不自动创建**；仅当库内已有该用户时可用 |
| LoginView 填入区 | lishang | LiShang1! | user | **不自动创建**；仅当库内已有该用户时可用 |

**干净本机一键跟做（admin）** — 与根 `README.md` 一致：

```bash
export FSA_DATA_ROOT="$(pwd)/data"
export FSA_BOOTSTRAP_ADMIN_USER=admin
export FSA_BOOTSTRAP_ADMIN_PASSWORD='Phase0Demo1!'
export FSA_OPENCODE_BASE_URL=http://127.0.0.1:4096
# backend: uvicorn app.main:app --host 127.0.0.1 --port 18000
# frontend: npm run dev -- --host 127.0.0.1 --port 5173
```

登录页：http://127.0.0.1:5173/login  
页内默认已填 `admin` / `Phase0Demo1!`，或点「填入」。
