## API 对照（同会话 bootstrap 路径）

```text
POST /api/v1/auth/login {"username":"admin","password":"Phase0Demo1!"} → 200 + user.role=admin
GET  /api/v1/me → 200 + username=admin
GET  /api/v1/health → status=ok, db.ok=true, schema_version=1
  （OC 未起时 opencode.ok 可为 false — 诚实；本跑次本机 OC 在线故 ok=true）
POST 错误密码 → 401
```

## 源码结构锚点（防空壳）

- `frontend/src/router/index.js`：`/login` → LoginView；`/` → HomeView（工作台）
- `LoginView.vue`：`login()` 成功后 `router.replace({ name: "home" })`；默认密码 `Phase0Demo1!`
- `HomeView.vue`：`fetchMe` + `fetchHealth`；无会话则回登录

## 结论

**主路径可跟做**：登录 admin → 工作台有用户/health/OC/入口，满足 W0 G3「点了→看到」。
