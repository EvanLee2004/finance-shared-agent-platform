## 交付摘要

本机可登录的中台地基：

1. **DB**：`FSA_DATA_ROOT`（默认仓库旁 `data/`）+ 全量 `schema_mvp.sql`（设计目录同源复制）+ `schema_meta.version=1` + `foreign_keys=ON` / WAL / `busy_timeout=5000`
2. **Auth**：`POST /api/v1/auth/login|logout|change-password`、`GET /api/v1/me`；Argon2id；HttpOnly Cookie `fsa_sid`；库存 SHA-256(token)；改密吊销全部 session；最小 audit（login/logout/password_change）
3. **Bootstrap**：`FSA_BOOTSTRAP_ADMIN_USER` / `FSA_BOOTSTRAP_ADMIN_PASSWORD` 仅当无 admin 时创建
4. **Health/Ready**：`GET /api/v1/health` 含 `schema_version`；OC 不可达时仍 200 且 `opencode.ok=false`；仅 `adapters/oc_client.py` 访问 OC；`/ready` 反映 DB+schema
5. **Vue3 登录壳**：`/login` + Home（用户名/role）+ 登出；dev proxy → `127.0.0.1:18000`；无聊天 UI
6. **门禁**：`sh tests/run_verify.sh` → EXIT:0（secrets、compileall、ruff、pytest、frontend build）
