# W9 模块地图

## 树状（backend）

```text
backend/app/
  main.py                 # lifespan · AppError · validation envelope · routers
  api/v1/                 # 薄路由：Pydantic 入参 + 调 service
    auth.py me.py health.py chats.py skills.py system.py deps.py
  services/               # 业务编排（隔离、授权、审计）
    auth_service.py chat_service.py skill_service.py
    oc_service.py         # ★ 路由访问 OC 的唯一服务门面
    audit_service.py
  adapters/               # 出站 I/O
    oc_client.py          # ★ 唯一 HTTP 打 OpenCode
    skills_repo.py        # catalog/git 本地 skills
  domain/                 # 无 I/O：enums errors ids
  db/                     # connection migrate schema
```

## 依赖方向（强制）

```text
frontend ──HTTP──► api/v1 ──► services ──► adapters ──► OC / FS / SQLite
                      │            │
                      └────────────┴──► domain (enums/errors)
```

**禁止**：

- `api/*` import `adapters.oc_client`
- `services/*` import `api/*`
- 第二处 `httpx` 访问 OC session/model/health

## 前端

```text
frontend/src/
  api/client.js     # 仅中台 /api/v1
  views/*           # UI；isAdmin 仅控制展示，写操作以后端 403 为准
  components/StateBlock.vue
```
